# Portafolio RX

Portafolio estático de RX (@yamix-rx), construido con HTML, CSS y JavaScript. Incluye proyectos públicos, filtros por categoría, modo claro y oscuro y diseño adaptativo.

## Publicación en Vercel

Al importar el repositorio `yamix-rx/yamix-rx` en Vercel, establece el **Root Directory** en `portafolio`. Framework Preset: **Other**. No es necesario un comando de compilación. Publica la rama `main`.

El README del perfil de GitHub en la raíz del repositorio no se modifica.
